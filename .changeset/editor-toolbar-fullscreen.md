Rich text editor: the toolbar stays on one row and tools that don't fit move into a "More tools" menu. New fullscreen mode (expand button at the toolbar's right end; Escape closes it) with the entry title and save status in its header. The inline editor has a fixed height that scrolls and can be dragged taller, like a textarea. The image alt text input moved from the toolbar to its own bar under it. New `Menu` component (and `MenuProps`, `MenuAction` types) in `@n3wtou/mnml-cms/admin`. Not breaking.
