# Extending the editor

Add Tiptap extensions and toolbar buttons.

The editor runs in the browser and `<RichText>` runs on the server. Both need the same extensions. So the config lives in a plain module that both import (no `'use client'`):

```ts filename="src/mnml-editor.ts"
import { defineEditor, tools } from '@n3wtou/mnml-cms/editor';

export const editor = defineEditor({
  extensions: [], // added to the defaults (StarterKit + Image)
  tools: [tools.underline, tools.strike, tools.horizontalRule],
});
```

A 3-line client file wraps it for the admin:

```tsx filename="src/mnml-editor-client.tsx"
'use client';
import { editorProvider } from '@n3wtou/mnml-cms/admin';
import { editor } from './mnml-editor';
export const Editor = editorProvider(editor);
```

Then:

- pass `editor: Editor` to `createCms`
- pass `editor={editor}` to every `<RichText>`

```tsx
<RichText content={post.content} editor={editor} />
```

The config applies to every rich-text field. It can't be set per field: extensions and functions can't be stored in the schema sent to the admin.

## Ready-made tools

`tools.underline`, `tools.strike` and `tools.horizontalRule` are buttons for things StarterKit already has. They need no extension.

## Your own tools

A tool is an object:

```ts
type EditorTool = {
  name: string;
  label: string;
  icon: ReactNode;
  run: (editor: Editor, admin: ToolContext) => void;
  isActive?: (editor: Editor) => boolean;
  disabled?: (editor: Editor) => boolean;
  visible?: (editor: Editor) => boolean;
  context?: string;
  builtIn?: boolean;
  group?: 'format' | 'block' | 'insert';
};
```

| Property | What it does |
| --- | --- |
| `name` | Unique. Used as the React key. |
| `label` | Tooltip and accessible name |
| `run` | Runs on click. `admin` has `form()`, `confirm()` and `alert()` ([Nodes with a form](/editor/nodes-with-a-form)). |
| `isActive` | Shows the button as pressed |
| `disabled` | Disables the button |
| `visible` | Shows the button only when it returns true |
| `context` | A node name. The tool shows in a small toolbar above that node while the cursor is in it. |
| `builtIn` | Set on the package's ready-made tools |
| `group` | The toolbar group. Without one, the tool gets its own group at the end. |

`run`, `isActive`, `disabled` and `visible` get the live Tiptap editor.

## Toolbar groups

In order:

1. Undo and redo
2. The text style menu: paragraph, headings, quote
3. `format`: bold, italic, code
4. `block`: lists
5. `insert`: link, image

- `tools.underline` and `tools.strike` go in `format`. `tools.horizontalRule` goes in `insert`.
- In each group, the package's ready-made tools (`tools.underline`, `tables.tools`…) come first.
- Your tools follow, in the order you list them.

## Example: code blocks with syntax highlighting

StarterKit has a plain code block. Swap it for [`CodeBlockLowlight`](https://tiptap.dev/docs/editor/extensions/nodes/code-block-lowlight) and add a button.

To replace or remove a default extension, pass a function. It gets the defaults and returns the full list.

```tsx filename="src/mnml-editor.tsx"
import { defineEditor } from '@n3wtou/mnml-cms/editor';
import CodeBlockLowlight from '@tiptap/extension-code-block-lowlight';
import { common, createLowlight } from 'lowlight';
import { SquareCodeIcon } from 'lucide-react';

export const editor = defineEditor({
  extensions: (defaults) => [
    ...defaults.map((ext) => (ext.name === 'starterKit' ? ext.configure({ codeBlock: false }) : ext)),
    CodeBlockLowlight.configure({ lowlight: createLowlight(common) }),
  ],
  tools: [
    {
      name: 'codeBlock',
      label: 'Code block',
      group: 'block',
      icon: <SquareCodeIcon />,
      isActive: (e) => e.isActive('codeBlock'),
      run: (e) => e.chain().focus().toggleCodeBlock().run(),
    },
  ],
});
```

The highlighting only shows in the editor. `<RichText>` renders `<pre><code class="language-…">`. On the site, highlight it with any highlighter, or style it as plain code.
