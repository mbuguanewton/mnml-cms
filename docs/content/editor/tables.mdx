# Tables

Tables have their own entry point. Sites without tables don't load the table code.

Spread its extensions and tools into the editor config:

```tsx filename="src/mnml-editor.tsx"
import { defineEditor } from '@n3wtou/mnml-cms/editor';
import { tables } from '@n3wtou/mnml-cms/table';

export const editor = defineEditor({
  extensions: [...tables.extensions],
  tools: [...tables.tools],
});
```

## In the editor

- **Insert table** adds a 3×3 table with a header row. The button comes before your own insert buttons.
- While the cursor is in a table, a small toolbar shows above the table's right end. It can:
  - add or delete a row or column
  - toggle the header row
  - delete the table
- Row and column buttons act on the cell the cursor is in.
- The toolbar hides when the cursor leaves the table or the editor.

## On your site

`<RichText editor={editor}>` renders a plain `<table>` with `<th>` and `<td>` cells, with no column widths. The admin styles it. Style it on your site like the rest of your prose.

## Your own floating tools

Your tools can use the same floating toolbar. Give a tool `context: 'callout'`: it shows above the nearest `callout` node while the cursor is inside it.
