# Entry points

| Import | Contents |
| --- | --- |
| `@n3wtou/mnml-cms` | Schema builders, validation, types, `seoMetadata`. Framework-free. |
| `@n3wtou/mnml-cms/next` | `createCms` (with the MCP server, see [Agents](/agents)), `neonDatabase`, `drizzleStorage`, `vercelBlobMedia`, `localMedia` |
| `@n3wtou/mnml-cms/proxy` | `adminProxy` |
| `@n3wtou/mnml-cms/rich-text` | `RichText` (server renderer), `collectReferences` |
| `@n3wtou/mnml-cms/editor` | `defineEditor`, ready-made `tools` (including `tools.node` and `tools.reference`), `nodeAttributes`, `referenceNode`, `collectReferences`, and the `RichTextComponents` and `RichTextNodeProps` types. Server-safe. |
| `@n3wtou/mnml-cms/table` | `tables`: table extensions and toolbar buttons for rich text. Server-safe. |
| `@n3wtou/mnml-cms/admin` | UI pieces for extra admin pages, `editorProvider` |
| `@n3wtou/mnml-cms/sync` | Content export and import, `mediaImporter` ([Moving content](/moving-content)). Runs without Next.js. |
| `@n3wtou/mnml-cms/db`, `@n3wtou/mnml-cms/schema` | The Drizzle table, for scripts and drizzle-kit. Two names for the same export. |
| `@n3wtou/mnml-cms/styles.css` | Admin styles and the `--mnml-*` variables |
