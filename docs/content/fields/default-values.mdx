# Default values

`default` is the value a new entry, array item or block starts with. Pass a value, or a function that returns one.

```ts
pageType: fields.select('Type', ['page', 'post'] as const, { default: 'page' }),
featured: fields.boolean('Featured', { default: false }),
date: fields.date('Date', { default: () => new Date().toISOString().slice(0, 10) }), // today
count: fields.number('How many', { default: 3 }),
```

- **Type-checked** against the field. A `select` default must be one of its options.
- **Only on create:** a new collection entry, a never-saved singleton, a new array item, a new block.
- **Never on read.** A field missing from stored data still reads as its empty value.
- **Functions run when the entry form opens.** Items and blocks added later in that form get the value from when it opened. Functions can't be sent to the browser.

Fields that take a `default`: `text`, `textarea`, `number`, `boolean`, `select`, `date`, `datetime`, `url`, `reference`, `references`, `tags`. For a `group`, give its fields defaults.
