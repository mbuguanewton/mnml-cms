# Default values

`default`: the starting value of a new entry, array item or block. A value, or a function returning one.

```ts
pageType: fields.select('Type', ['page', 'post'] as const, { default: 'page' }),
featured: fields.boolean('Featured', { default: false }),
date: fields.date('Date', { default: () => new Date().toISOString().slice(0, 10) }), // today
count: fields.number('How many', { default: 3 }),
```

- **Type-checked.** A `select` default must be an option.
- **Create only:** new collection entry, never-saved singleton, new item, new block.
- **Never on read.** Missing stored fields read as empty.
- **Functions run when the form opens.** Later items in that form reuse that value (functions can't go to the browser).

Takes `default`: `text`, `textarea`, `number`, `boolean`, `select`, `date`, `datetime`, `url`, `reference`, `references`, `tags`. Groups: set defaults on their fields.
