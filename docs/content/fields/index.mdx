# Field types

Every field takes `{ required, help }`.

| Field | Value |
| --- | --- |
| `text`, `textarea` | `string` |
| `date` (`YYYY-MM-DD`), `url` | `string \| null` |
| `datetime` | `string \| null`, UTC (`2026-11-18T14:30:00.000Z`). Edited in local time. |
| `number(label, { min, max, step })` | `number \| null` |
| `boolean` | `boolean`, default `false` |
| `select(label, ['a', 'b'] as const)` | `'a' \| 'b' \| null`. Options can have [labels](/fields/select-labels). |
| `reference(label, 'authors')` | `string \| null`: a published entry's slug. Read with `cms.getEntry`. |
| `references(label, 'posts', { min, max })` | `string[]`: published slugs, in order. Read with `cms.getEntries`. |
| `image` | `{ url, alt, focalX?, focalY? } \| null`. [Focal point](/fields/focal-point) optional. In the admin: an empty field is a drop zone (drop, click or browse); a filled one is a preview with an icon toolbar (Replace, Choose from uploads, Focal point, Remove) and a `filename · width×height` chip. |
| `richtext` | Tiptap JSON. Render with `<RichText>`. |
| `tags` | `string[]` |
| `array(label, fields, { itemLabel, min, max })` | Repeatable list of `fields` |
| `group(label, fields)` | Nested object, one form section: `page.hero.headline` |
| `blocks(label, { hero: block('Hero', fields), … }, { itemLabel, min, max })` | Sections of different [blocks](/fields/blocks): `{ kind: 'hero', …fields }[]` |
| `seo(label?)` | `group` of `title`, `description`, `image` ([SEO](/fields/seo)) |

## Picking entries

`reference` and `references` use a search box: filter by title or slug, pick with ↓/↑ + Enter or a click.

- `reference`: shows the pick, with a clear (×) button.
- `references`: shows the picks. [Drag to reorder](#reordering-lists), remove, add up to `max`.

```ts
related: fields.references('Related posts', 'posts', { max: 3 }),
authors: fields.references('Authors', 'authors', { required: true }),
```

`references` validation:

- Slugs trimmed. Blanks and repeats dropped.
- Then `min` / `max`. `required` = at least one.
- An entry unpublished later stays, marked "(unavailable)". Readers skip it.

### Create new

Next to the search box, **Create new** opens a panel on the right with the target collection's form. Make the entry without leaving the one you're editing.

- **Publish** creates it live and picks it. **Save draft** creates a draft and picks it, shown as "(draft)". The picker doesn't list drafts, and readers skip them, until you publish.
- Slug follows the title until you edit it. Errors show per field and keep the panel open.
- Close or Cancel asks first if you typed anything.
- A reference field inside the panel has its own **Create new**.
- Turn it off per field: `fields.reference('Author', 'authors', { createNew: false })`.

## Reordering lists

`array`, `blocks` and `references` rows have a grip on the left. Drag it to move the row.

- Mouse, touch and pen. A line shows where the row will drop. Letting go away from the list, or pressing Escape, cancels.
- Keyboard: focus the grip, then ↑ / ↓ move the row one place, Home and End to the top or bottom. Focus stays on the row, and a screen reader hears the new position.
- An open row stays open while it moves, and a row's validation errors move with it (also when a row is removed). Order is the order readers get.

## Groups become tabs

Groups add tabs above the form: **All fields**, **General** (fields outside groups), one per group.

A page with fixed sections: one singleton, a group per section. Editors add pages: a collection.
