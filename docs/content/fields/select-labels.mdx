# Select labels

An option is a value, or a value with a label. The admin shows the label. You can mix both forms.

```ts
category: fields.select('Category', ['news', { value: 'guide', label: 'How-to guide' }] as const), // 'news' | 'guide' | null
```

- The value type is still inferred from the values.
- Entries, `default`, `showIf` and validation all use values, not labels.
- A value listed twice throws when the config loads.

To show the label on your site, pass the field from your config to `selectLabel`:

```ts
selectLabel(config.posts.fields.category, post.category);
```
