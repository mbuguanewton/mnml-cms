# mnml-cms

A small CMS that lives inside your Next.js site.

- **One config file** defines your content.
- **The admin** is a route in your app (`/admin`).
- **Entries** are stored in your own Postgres, in one JSON table. Changing the content model never needs a migration.

Needs Next 16+ (App Router), React 19+ and Tailwind v4.

Start with [Getting started](/getting-started). For a complete app, see [`example/`](https://github.com/mbuguanewton/mnml-cms/tree/main/example).
