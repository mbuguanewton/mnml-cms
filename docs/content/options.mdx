# Options

Second argument of `createCms(config, options)`.

| Option | Purpose |
| --- | --- |
| `database` | Drizzle Postgres database, or a function returning one (called on first use) |
| `table` | Table name, with `database`. Default `entries`. |
| `storage` | Your own `EntryStorage` instead of `database` ([Other ORMs](/other-orms)) |
| `auth` | `{ password, secret }` for the built-in login, or an `AuthAdapter` ([Authentication](/authentication)) |
| `media` | Image storage ([Image storage](/image-storage)) |
| `adminPath`, `apiPath` | Default `/admin`, `/api/mnml`. Must match the route files. |
| `brand` | Name and logo of the sidebar and sign-in page: a string, `{ name, logo }`, or an (async) function returning either ([Brand and logo](#brand-and-logo)) |
| `icons` | Sidebar icons per key, e.g. `{ posts: <FileTextIcon /> }` |
| `pages` | Extra admin screens: `{ path, label, group?, icon?, render }`. Build with `@n3wtou/mnml-cms/admin`. |
| `listActions` | Your own actions in a collection list's bar, per key: `{ posts: [{ name, label, danger?, confirm?, run }] }` ([Bulk actions](/drafts-and-publishing#bulk-actions)) |
| `editor` | Component from `editorProvider()`: extra extensions and buttons ([Extending the editor](/editor)) |
| `ui` | Component from `uiProvider()`: your own Button, Select… in the admin ([Custom admin UI](/custom-admin-ui)) |
| `mcp` | `{ tokens, adminTokens }`: MCP server for AI agents at `<apiPath>/mcp`, with tokens from env and/or the admin ([Agents](/agents)) |
| `search` | `{ index, route }`: search over published content, `cms.search()` and a `search_content` MCP tool. `index` is your own `SearchIndex` (Postgres, pgvector, Mongo, Convex…); `route` opens a public search route ([Search](/search)) |
| `cache` | `true` or `{ revalidate }` (seconds, default 3600): keeps published reads between requests, dropped on each save or delete. Off by default, recommended ([Caching](/reading-content#caching)) |
| `revalidate` | After each save or delete, with `{ type, key, slug, by? }`. `by`: the agent token's name. |
| `onChange` | After the response (via `after()`) on each save or delete, e.g. to update a search index. Same change as `revalidate`. |

## Brand and logo

`brand` is the name in the sidebar and on the sign-in page. Give it an object to add your logo:

```ts
createCms(config, {
  brand: { name: 'Example', logo: '/logo.svg' },
});
```

`logo` is one of:

- A URL (a file in `public/`, or any absolute URL). Replaces the letter tile; the name stays beside it.
- `{ src, dark?, alt?, wordmark? }`. `dark` is shown in the admin's dark theme. `wordmark: true` hides the name and sizes the image by its height, for a logo that already contains it. `alt` defaults to empty, or to the name with `wordmark`.
- A React element, e.g. an inline SVG using `currentColor`.

If the image fails to load, the letter tile is shown. A plain string, or a function returning a string or object, works as before.

## In your own code

- `cms.isAdmin()`: checks the session in your routes. Works with the built-in login and adapters.
- `useAdmin()` from `@n3wtou/mnml-cms/admin` opens the admin's dialogs and toasts in custom admin pages:

```ts
const { confirm, alert, toast } = useAdmin();
await confirm({ title: 'Delete?', description: '…', confirmLabel: 'Delete', danger: true }); // true or false
toast({ title: 'Saved', tone: 'success' }); // tone: 'info' | 'success' | 'danger'; duration in ms, 0 = stays
```

## Admin UI components

Build `pages` with the admin's own controls from `@n3wtou/mnml-cms/admin`. To use your own instead, see [Custom admin UI](/custom-admin-ui). Client components. No extra dependencies. Styled with `--mnml-*`.

| Component | Props |
| --- | --- |
| `Button` | `variant`, `size`, `disabled`, `onClick`, `children` |
| `Input`, `Textarea` | `id`, `value`, `onChange(value)`, `placeholder`, `disabled`, `invalid`. `Input` also `type` (number, date, datetime-local stay native, restyled). |
| `Select` | `id`, `value` (string or null), `onChange(value)`, `options: { value, label }[]`, `placeholder`, `clearable`, `invalid` |
| `Checkbox`, `Switch` | `id`, `checked`, `onChange(checked)`, `disabled`, `label` |
| `DatePicker` | `id`, `value` (`YYYY-MM-DD` or null), `onChange(value)`, `time` (adds a time box; value `YYYY-MM-DDTHH:mm`), `timeInCalendar` (with `time`: one box, time row in the calendar), `invalid` |
| `Tooltip` | `content`, `side`, one focusable child. Shows on hover and keyboard focus. |
| `Menu` | `label`, `items: { id, label, icon, checked, disabled, danger, keepOpen, onSelect }[]`, `trigger`, `className` |

- `onChange` gets the value, not the event.
- `Select`: full width; cap it with a `max-w-*` class. Arrows, Home/End, type-ahead, Enter, Escape. A value that isn't an option shows as "(unavailable)".
- `Menu`: a "more" icon button by default; pass `trigger` for your own content. Set `checked` for on/off items. Arrows wrap, Home/End, type-ahead, Escape.
- Label a control with `<label htmlFor={id}>`, the `label` prop, or `aria-label`.
- Prop types are exported: `SelectProps`, `CheckboxProps`, `MenuProps`, `MenuAction`, `ToastOptions`, …

```tsx
'use client';
import { Select, Switch, useAdmin } from '@n3wtou/mnml-cms/admin';

const { toast } = useAdmin();
<Select id="section" value={section} onChange={setSection} options={[{ value: 'posts', label: 'Posts' }]} />
<Switch checked={on} onChange={setOn} label="Confirm first" />
```
